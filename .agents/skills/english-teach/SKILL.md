# English

Apply [homework-teach](../homework-teach/SKILL.md). Map the reading or writing decisions and the required response. Use unrelated language, passages, imagery, characters and claims.

- Separate observation, plain meaning and interpretation. Check each paraphrase against its wording for actor, action, timing, frequency, negation, uncertainty and conditions. Distinguish speaker, character, narrator and author. Find the smallest useful quotation in a fresh unmarked passage with comparable evidence density. Include plausible alternatives and explain how wording supports a bounded claim.
- When translating older language, teach needed pronouns, verbs and word order with new lines, then bridge literal meaning to natural English. If analysis is also required, use the same new line to show how a device shapes meaning. Use genuine details to build tempting alternatives.
- Match the requested claim and genre. For a two-source argument, open with complete original readings in comparable forms. Preserve abstract claims and qualifications when the source uses them. Include plausible details whose value requires interpretation. Before teaching the strategy, ask for one detail from each and a provisional claim. Ask what the second reading changes or establishes that the first could not. Then reveal an annotated model that introduces and attributes evidence, explains both roles and revises the claim. End with the independent writing the task requires.
- Keep passages visible during decisions. Group a marked quotation, explanatory note and caption in one figure. Move from annotation to an uncued attempt. Verify exact quotation, grammar and the evidence link. Check mobile/print reading and visible, contrasting keyboard controls. Give a bounded way to check the learner's own work privately.
