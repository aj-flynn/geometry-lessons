# English

Apply [homework-teach](../homework-teach/SKILL.md). Map the reading or writing decisions and the required response. Use unrelated language, passages, imagery, characters and claims.

- Separate observation, plain meaning and interpretation. Preserve actor, negation, uncertainty, conditions and questions. Distinguish speaker, character, narrator and author. Find the smallest useful quotation in a fresh unmarked passage with comparable evidence density. Include plausible alternatives and explain how wording supports a bounded claim.
- When translating older language, teach needed pronouns, verbs and word order with new lines, then bridge literal meaning to natural English. If analysis is also required, use the same new line to show how a device shapes meaning. Use genuine details to build tempting alternatives.
- Match writing to the requested genre. For a two-source argument, use original readings with comparable syntax, abstraction and overlapping qualified claims. Keep the reading only as long as those decisions require. Before seeing a model, choose a useful detail from each, explain the distinct work each does for a shared claim, then narrow the claim to fit a condition or exception. Turn that evidence map into a complete argument plan. Model a complete evidence-to-claim paragraph and its revision. Ask for the independent writing the task requires.
- Keep passages visible during decisions. Group a marked quotation, explanatory note and caption in one figure. Move from annotation to an uncued attempt. Verify exact quotation, grammar and the evidence link. Check mobile/print reading and visible, contrasting keyboard controls. Give a bounded way to check the learner's own work privately.
