# Geometry: decide what the givens justify

Read [homework-teach](../homework-teach/SKILL.md) for the shared privacy, routing, lesson, review, and delivery contract. This skill supplies geometry decisions. Keep the subject `Geometry`, existing URLs, and compatible shared assets.

## Translate the demand, privately

Visually inspect every supplied figure, including angle arcs, tick marks, parallel arrows, right-angle boxes, orientation, units, and the order of named vertices. Separate stated givens from apparent measurements. Handwriting is neither proof nor permission to confirm an answer. If an essential mark is unreadable, ask about that mark instead of inferring it.

Map the underlying demands to the teaching: matching parts; selecting a theorem and checking its conditions; computing or comparing a quantity; interpreting a diagram; and justifying a claim. Include only relevant demands. For each, plan an original worked example or explanation followed by a new transfer check. A topic mention is not coverage. Keep the map and assignment comparisons private. Change configurations, representation, question direction, and context as well as values.

Offer an optional prerequisite check before formal notation. Explain each symbol on first use, including angle names, similarity/congruence signs, ratios, variables, and units. A learner who cannot yet compare a pair of lengths should have a short numerical bridge before a chain of proportions.

## Make the evidence visible

Use computed coordinates for accurate diagrams. Mark the givens explicitly and label a schematic as schematic. The picture's orientation, apparent size, or visual symmetry does not establish a theorem condition. When the source uses marks to establish correspondence, teach the learner how to read those marks, not merely the author how to inspect them. Explain repeated angle-arc patterns, side ticks, or other relevant markings; an arc count identifies an equality group, not a number of degrees. Use an original worked marked-figure example to derive vertex pairs, followed by a distinct transfer check with no ordered similarity statement supplied. Then match an edge by both endpoints and use that correspondence consistently in angle statements and ratios. A turn or reflection may change position without changing which parts correspond.

Choose a visual that exposes the key decision: a rotated figure for correspondence, an allowed example and counterexample for a claim, or a dimension model for scaling. Pair it with a text equivalent containing the same givens and relationship. Verify geometry, labels, descriptions, formulas, and interaction states agree at every endpoint and at one intermediate state. Test SVG label legibility at its rendered mobile size, and measure text bounds against the viewBox at both endpoints and an intermediate state. Reserve room for the longest formatted label during animation, which can contain more decimal digits than a settled slider value. Keep equal unit scales in comparison diagrams when changing their bounds.

## Similarity and dimensional reasoning

When similarity is relevant:

- Establish that the figures are similar before using one uniform factor. For general polygons, corresponding angles and side ratios both matter; use a triangle shortcut only when its hypotheses are given.
- Name the comparison direction before calculating: target divided by original. Keep the direction and units consistent across every ratio; reverse with the reciprocal.
- Separate invariants from scaled quantities: angle measures remain equal; lengths and perimeter use the length factor; area uses its square. Explain perimeter by adding scaled sides, and area by combining two scaled lengths. Uniform enlargement changes side lengths without changing angle measures.
- When the assignment requires a complete correspondence or proportion record, demonstrate its full structure on a new figure. Practice scaling in both directions and distinguish a ratio named in a question from the direction of the transformation. Connect ratios to actual quantities. A factor is unitless; a new perimeter needs the original perimeter, and a new area needs the original area. Include a fresh nonrectangular transfer when the explanation uses rectangles, and include a reduction when enlargement is the starting model.
- Give a purposeful prediction, observation, and explanation prompt around the manipulative. Keep any sentence about the current state synchronized with the controls, or label it explicitly as a fixed worked state. Preserve reset, pause, reduced motion, and a useful static example.

When the private source requires always/sometimes/never reasoning, demonstrate and check each relevant evidence burden in the integrated lesson. A worked always case and a sometimes check do not demonstrate never. For universal claims, teach the burden of evidence: a reason covering all allowed cases for always; one allowed case in each direction for sometimes; a contradiction for every allowed case for never. Check that each proposed case satisfies the givens and defines a possible geometric figure. Use a genuinely separate geometric claim for practice, with feedback on why evidence is sufficient. Avoid a general fact that would itself classify an assigned case.

## Return the decision to the learner

After a worked example, change the representation or requested quantity. Start feedback with the reasoning the learner should revisit, and permit a retry. Include mixed practice that requires selecting the relationship rather than merely substituting into the displayed formula. Support an exit explanation with a self-check of evidence, direction, units, and whether the result should be larger or smaller. Automatic checking of a fresh numerical result does not grade a free-text explanation or establish mastery.

Preserve a complete static exercise: its question, every answer choice, and an initially closed comparison explanation. Numeric exercises need a worked comparison with units. Show this version when enhancement is unavailable and in print; hide it only after the interactive check is successfully ready. Initialize the exercise’s required handlers before exposing controls or hiding static comparisons; express required script dependencies explicitly. Check the integrated page with JavaScript disabled and each required script blocked individually, not merely the generated fragment or top-level module.

Read the complete learner-facing source destination before linking it. Check both mathematical accuracy and meaningful separation from the private task, including theorem summaries and worked examples. Prefer a narrower relevant destination when a broad reference would supply an assigned classification. An author verification reference is not automatically a safe learner recommendation. Record source changes in the shared resource list through its owner.
