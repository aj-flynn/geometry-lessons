# Review and publish

Apply the [shared skill](../SKILL.md) to the exact lesson and its local dependencies. The author performs this check. For a material doubt that needs another judgment, use a fresh GPT-6.1 Sol agent for the specific issue. Keep source maps and comparisons private.

1. Compare every visible or hidden example, hint, answer key, feedback attribute, glossary, and direct learner destination against the supplied assignment. Inspect filenames, comments, metadata, visuals and text alternatives for privacy and homework separation.
2. Verify claims, arithmetic, units, theorem conditions, assumptions, representation agreement, and credible sources. Check that required reasoning has original transfer and a route back to independent work.
3. Exercise keyboard use, contrast, focus, feedback, responsive reflow and enlarged text, motion controls, no JavaScript, individual script failure, and print. Check actual page behavior including library return, no response requests or storage, and meaningful fallback. Repeat affected checks for every consumer of changed shared assets. Report observed limits.
4. Update version-2 lessons.json with the registered subject, public title/summary/topics, and truthful privacy, homeworkSeparation, accuracy, and accessibility attestations. Keep existing filenames; number new lessons sequentially within the library. Preserve legacy Geometry compatibility. Hash LF-normalized HTML bytes and obtain review.dependencies and review.contract using collectLessonDependencyHashes(base, file) and collectReviewContractHashes(base, subject) from scripts/check.mjs. The closure includes local references and transitive assets. Refresh claims only after review.
5. Use the static loading convention. Put literal, semicolon-terminated local imports at the start of scripts. Bind events with addEventListener. Use literal local CSS resources. Keep dynamic loading, inline handlers, embedded documents, navigation tricks, and response tracking out of learner pages. The checker is a guard; inspect meaning and executable behavior.
6. On a fresh checkout use npm ci --ignore-scripts. Rebuild with node scripts/build-index.mjs, then run node scripts/check.mjs and node --test tests/*.test.mjs. Run affected browser checks in the [README](../../../../README.md).
7. Inspect the explicit staged paths and commit text for privacy. Recheck the authorized destination, publish reviewed lesson, skill, dependencies, manifest and index together, and run check-live.py against that site. Verify reviewed bytes and actual keyboard navigation. Verify deployment before giving the lesson and library URLs through the approved originating route. Report any pending delivery.
