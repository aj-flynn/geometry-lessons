Introductory chemistry / Naming compounds

What a compound name counts

Use charge to read an ionic formula. Use atom counts to translate between a molecular formula and its name.

Start with the position of the number

Write each response before using the comparisons near the end.

An ion is a charged atom or group of atoms. In CO32−, which number counts oxygen atoms, and which tells you the charge of the whole ion?

Compare the two numbers

The lower 3 is a subscript. It counts three oxygen atoms. The upper 2− is a superscript. It gives the charge of the entire group. The C has no subscript, so there is one carbon atom in the group.

A subscript counts what it follows. An unwritten count means one. A superscript charge such as 2− gives the sign and size of a charge.

1. Find the charge on one metal ion

Two copper formulas

CuCl2 and CuCl

Both are neutral. Copper can form ions with different charges. The ion lookup gives Cl−, chloride, for each chlorine in these formulas.

An ionic compound contains cations (positive ions) and anions (negative ions). Their charges add to zero. Start with the known negative charge and find the total positive charge needed to cancel it.

  1. CuCl2 has one Cu ion and two chloride ions in its formula unit, the smallest whole-number ratio of its ions.
  2. Two chloride ions contribute 2 × (−1) = −2.
  3. Neutrality requires +2 in total. One Cu ion supplies all of it.
  4. Write copper(II) chloride. The Roman numeral gives the charge on one copper ion in this compound. Use the anion name, chloride, after the metal name.

Now read CuCl. One chloride contributes −1, so the single copper ion supplies +1. Its name is copper(I) chloride. The two formulas show why the name needs the charge.

If there are several metal ions of the same charge in a formula unit, divide the total positive charge by the number of metal ions before writing the numeral.

Try a formula with two metal ions

Name Cu2Se. Use the ion lookup for selenium’s ion. Work out the charge on each copper ion.

Compare the metal charge

One selenide ion contributes −2. The two copper ions supply +2 together. Divide by 2 to get +1 each, so the name is copper(I) selenide. If you wrote copper(II), revise your charge line to show how much each of the two ions supplies. Then try a new metal in mixed practice.

2. Balance charges with the group intact

A pair of ions

Al3+ and SO32−

Goal for this pair. Write a neutral formula and its name. Find the exact group in the ion lookup.

A polyatomic ion is a group of bonded atoms that carries a charge as a unit. Change how many copies you use while keeping the group’s formula and charge fixed.

  1. The first positive total divisible by both charge sizes, 3 and 2, is 6.
  2. 2 × (+3) = +6 from two aluminum ions.
  3. 3 × (−2) = −6 from three of the given groups. The totals cancel.
  4. Write Al2(SO3)3. The 3 inside counts oxygen atoms in one group. The 3 outside counts whole groups. The neutral formula leaves out the ion charges.
  5. Match SO32− in the lookup to sulfite. The compound is aluminum sulfite. Aluminum has a fixed charge in this naming system, so its name needs no numeral.

With just one copy of a group, leave out the parentheses and the 1. For example, Cu2+ and CO32− cancel one to one. Write CuCO3, copper(II) carbonate. Here the given copper charge goes into the name.

Predict what changes

Pair Al3+ with SO42− this time. Write the new formula and name. Which count changes, and which stays the same? Use the ion lookup if needed.

Compare the two ion groups

The charges and the two-to-three ratio stay the same. Each group now contains four oxygen atoms. Write Al2(SO4)3, aluminum sulfate. If you changed the outer 3, compare the two group charges first. If you kept the name sulfite, match the entire new ion in the lookup. Revise both parts, then try the chlorine groups in mixed practice.

3. Read counts in a molecule

Read in both directions

Cl2O

First write the molecular name for this formula.

disulfur dichloride

Then write the formula for this molecular name. Use the prefix key and element-symbol reference.

A molecular formula counts the atoms in one molecule. In the names we’re practicing, a prefix at the start of each name part gives that element’s count. Keep the order in the given formula or name.

  1. For Cl2O, the first element is chlorine. Two chlorine atoms give dichlorine.
  2. The second element, oxygen, takes the -ide form oxide. One oxygen gives monoxide. Together the name is dichlorine monoxide.
  3. If the first element has a count of one, omit mono- from the first word. A count of one on the second element keeps it.

Read disulfur dichloride in order. The first di- gives two sulfur atoms. The second di- gives two chlorine atoms. Write S2Cl2. Reducing both counts would change the number of atoms in one molecule.

Try an unwritten count

Name SF6. Which word needs a prefix? Use the prefix key if needed.

Compare the two name parts

Sulfur hexafluoride. One sulfur is written without mono- because sulfur comes first. Six fluorine atoms give hexa- plus fluoride. If you wrote monosulfur, revise the first word. Apply the rule again in mixed practice, then read a prefix from a name back into a formula.

An unwritten count

Sulfur hexafluoride. One sulfur is written without mono- because sulfur comes first. Six fluorine atoms give hexa- plus fluoride. If you wrote monosulfur, revise the first word. Apply the rule again in mixed practice, then read a prefix from a name back into a formula.

1. Compare the compound names

Three selenides total 3 × (−2) = −6. Each of the two chromium ions supplies +3, so write chromium(III) selenide. Four fluorides total 4 × (−1) = −4. One titanium supplies +4, so write titanium(IV) fluoride. If both numerals came from a subscript, replace each with the charge on one metal.

Back to the mixed practice

2. Compare the two ion pairs

Each group has a 1− charge, so two copies balance one Mg2+. The lookup gives magnesium chlorate, Mg(ClO3)2, and magnesium chlorite, Mg(ClO2)2. If you switched the names, trace each inner subscript back to its own lookup row. The outer 2 is shared by both formulas.

Back to the mixed practice

3. Compare the formula and name

One Cr3+ needs three hydroxide groups. Write Cr(OH)3, chromium(III) hydroxide. If your subscript follows H with no parentheses, it counts H alone. Redraw the three whole groups, then gather them inside parentheses with a 3 outside.

Back to the mixed practice

4. Compare the molecular names

Selenium hexafluoride has one selenium and six fluorines. Tetraphosphorus trisulfide has four phosphorus and three sulfur atoms. If you omitted tetra-, check the first subscript. First position omits the prefix only for one.

Back to the mixed practice

5. Compare the molecular formulas

Diphosphorus tetrafluoride gives P2F4. Xenon tetrafluoride gives XeF4. If you reduced the first formula, write each prefix count alongside its element and copy both counts into the formula. Xe is one symbol, with an uppercase X and lowercase e.

  • When naming a variable-charge metal, find the charge on one metal ion.

Glossary

Ion
An atom or group of atoms with a net electric charge.
Subscript
A lower number that counts the preceding element or parenthesized group.
Superscript
An upper symbol. An ion’s superscript gives its charge.
Ionic compound
A neutral substance made up of positive and negative ions.
Cation
A positively charged ion.
Anion
A negatively charged ion.
Formula unit
The smallest whole-number ratio of ions shown by an ionic formula.
Roman numeral
In the metal names here, (I), (II), (III), (IV), (V), and (VI) give charges 1+ through 6+ on one ion.
Polyatomic ion
A bonded group of atoms with a net charge.
Molecular formula
The symbols and exact atom counts for one molecule. This formula gives composition. A structure diagram can also show how the atoms are connected.
Prefix
A beginning added to a name part. The molecular prefixes in this lesson indicate counts of atoms.

This lesson uses simple ionic charge bookkeeping and the introductory prefix convention for two-element molecular compounds.
