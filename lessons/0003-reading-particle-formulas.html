Problem type 1

Count the atoms in one particle

Use this when a question asks how many of each atom a formula shows, or whether two formulas must share an arrangement.

Example: ethyl methanoate, C3H6O2. Two molecules are under consideration.

  • Ethyl methanoate: HCOOCH2CH3
  • Methyl ethanoate: CH3COOCH3

NIST’s ethyl methanoate record and methyl ethanoate record show the two named compounds.

Goal: report counts in one ethyl methanoate molecule and decide if the two entries must have the same arrangement.

  1. Name the unit

    One molecule fixes the unit

    unit: 1 molecule of C₃H₆O₂

    Ethyl methanoate is a molecular substance, so the formula counts the atoms in one molecule.

  2. Read a symbol

    C carries 3

    C₃ → 3 C

    Read one symbol at a time and attach its own number to it. The 3 belongs to C.

  3. Read a symbol

    H carries 6

    3 C · 6 H

    The next capital letter starts a new symbol. The 6 belongs to H.

  4. Read a symbol

    O carries 2

    3 C · 6 H · 2 O

    That gives 3 carbon, 6 hydrogen and 2 oxygen atoms per molecule.

  5. Find a shared group

    Find the COO group in each label

    C=O and C–O in both

    Methyl ethanoate, CH3COOCH3, has the same counts. In each label, the COO group’s C has a double link to one O and a single link to the other.

  6. Follow a link

    Follow the single link to O

    O–CH₂CH₃ vs O–CH₃

    After O, ethyl methanoate continues with CH2CH3; methyl ethanoate continues with CH3. The O-linked groups differ. That difference is about connectivity, which atoms link directly.

Tip: the arrow keys also move through the steps.

The steps

  1. Name the unit the formula counts.

    one molecule

    Why?

    A subscript counts atoms in one unit. For a molecule that unit is one particle; for an ionic solid it is a ratio, so decide which before using the numbers.

  2. Read one symbol at a time and attach its own subscript; no number means 1.

    C₃H₆O₂ → 3 C · 6 H · 2 O

    Why?

    A subscript modifies only the symbol or group written just before it. A capital letter always starts a new symbol, and a lowercase letter stays with the capital before it.

  3. To compare arrangements, find a group the labels share.

    COO in each

    Why?

    Matching counts say nothing about which atoms touch. A shared group gives a fixed place to start comparing connections.

  4. Follow each link out of that group and compare the neighbors.

    O–CH₂CH₃ vs O–CH₃

    Why?

    Connectivity is which atoms link directly. Two molecules with the same tally can still link their atoms differently, so check a drawing or condensed label.

Problem type 2

One molecule or a repeating ratio?

Use this when you must say what a formula counts: atoms in one molecule, or ions in a repeating ratio.

Examples: magnesium sulfide, MgS, a solid; hydrogen selenide, H2Se, separate molecules.

The sketches in the slides record connections and charges, not actual sizes or angles.

Selected element lookup
KindSymbols
MetalsMg
NonmetalsH, S, Se

  1. Look up the kinds

    Mg is a metal; S is a nonmetal

    Mg: metal · S: nonmetal

    In a lookup sorted by element kind, find Mg on the metals row and S on the nonmetals row. A metal with a nonmetal is a clue for an ionic model.

  2. Find the charges

    Each atom becomes an ion

    Mg → Mg²⁺ · S → S²⁻

    Magnesium loses two electrons in the simple charge model, giving Mg2+; sulfur gains two, giving S2−. Each charged atom is an ion. Opposite charges attract throughout a lattice, a repeating arrangement.

  3. Read the ratio

    The formula is a ratio in a lattice

    +2 and −2 → 1 : 1 → MgS

    A neutral ratio takes one of each, so MgS is a formula unit, the smallest ratio. The drawn boundary cuts a continuing ionic solid.

  4. Look up the kinds

    H and Se are both nonmetals

    H, Se: nonmetal + nonmetal

    Two nonmetals are a clue for shared electrons and separate molecules.

  5. Read the count

    The formula counts one molecule

    H₂Se: 2 H + 1 Se per molecule

    Each separate hydrogen selenide group has two H and one Se. These atoms share electrons in covalent bonds, links within each group. H2Se gives the count for one molecule. Its sketch records connections, not actual sizes or angles.

  6. Check the evidence

    Network or discrete group?

    MgS: ratio · H₂Se: one molecule

    Compare the partner types and the model evidence. Use that contrast as a clue for similar simple two-element samples. Evidence of an extended network or a discrete group can settle cases the element types leave uncertain.

Tip: the arrow keys also move through the steps.

The steps

  1. Find each symbol in the element-kind lookup.

    Mg: metal · S: nonmetal

    Why?

    For simple two-element samples, a metal with a nonmetal points to ions, and two nonmetals point to shared electrons. It is a clue, not a proof.

  2. For a metal with a nonmetal, find each ion’s charge and the neutral ratio.

    Mg²⁺ + S²⁻ → 1 : 1

    Why?

    Opposite charges must balance in a neutral solid. The smallest whole-number ratio that balances them is the formula unit.

  3. Read an ionic formula as a ratio in a lattice, not as one particle.

    MgS = formula unit

    Why?

    The ions continue in a repeating array, so no single MgS pair is a separate particle. The subscripts give how many of each ion per unit of the pattern.

  4. For two nonmetals, read the formula as one molecule.

    H₂Se = 2 H + 1 Se

    Why?

    Covalent bonds hold each group together, and the groups are separate, so the subscripts count atoms in one molecule.

  5. When element kinds leave it open, look for network or group evidence.

    extended → ratio · discrete → molecule

    Why?

    What the sample is made of, a continuing network or separate groups, decides what the formula counts. Element kinds only predict it.

Problem type 3

Ask two questions about an elemental sample

Use this when a question asks whether a particle is one element, two atoms, or both.

Example: One form of solid sulfur has ring units. Carbon monoselenide provides a comparison unit.

The sketches leave out actual bond orders and shape.

  1. Question 1

    How many atoms in one unit?

    ring: 8 atoms

    Count the labels in the sketch. The sulfur ring unit has eight.

  2. Question 2

    How many kinds of atom?

    ring: 1 kind → S₈

    Count the different symbols. The sulfur ring has only one kind, and its full formula is S8.

  3. Question 1

    Count the comparison unit

    C–Se: 2 atoms

    The C–Se particle has two atoms, so it is diatomic.

  4. Question 2

    Two atoms, but two kinds

    C–Se: 2 kinds

    It has two kinds of atom, so it is not a sample of one element.

  5. Know the limit

    A lone symbol does not give the grouping

    S ≠ S₈

    An isolated element symbol names an atom type, not how a sample is grouped. For an elemental form, read an elemental particle formula or a course reference that states the conditions and whether atoms occur separately or in groups. You cannot derive a roster of common elemental forms from the subscript rule.

Tip: the arrow keys also move through the steps.

The steps

  1. Count the atoms in one separate unit.

    ring: 8 · pair: 2

    Why?

    Diatomic describes the whole unit: exactly two atoms. The count comes from the particle formula or model, not from the element.

  2. Count the different symbols in that unit.

    ring: 1 kind · pair: 2 kinds

    Why?

    One kind of atom means the sample is one element. A two-atom unit can still mix two elements, so this is a separate test.

  3. For an element’s usual form, read a particle formula or reference for the stated conditions.

    S names an atom type; S₈ names a unit

    Why?

    An isolated symbol names an atom type, not how a sample is grouped, and the subscript rule cannot tell you which elements pair up.

Glossary

Subscript
A small lowered number written after an element symbol or a group. It multiplies that symbol or group within the formula. An unwritten subscript is 1.
Atom
One unit of an element; its chemical symbol names the element. A symbol starts with a capital letter and may have a second, lowercase letter.
Particle
An individual unit at the scale of the model; it can be an atom, a molecule or an ion.
Composition
In the two ester examples, compare the C, H and O tallies. They match even though the O-linked groups differ. Use that distinction when matching the course term to evidence.
Connectivity
Which atoms are direct neighbors. Compare the two ester examples to see which detail changes even when every atom count agrees.
Ion
An atom or bonded group with net electric charge. Losing electrons gives a positive charge; gaining electrons gives a negative charge.
Lattice
Here, the repeating arrangement of positive and negative ions in an ionic solid. A small drawing is a slice of that extended pattern.
Formula unit
For a simple ionic solid, the lowest whole-number ratio of the ions, written as a chemical formula. It is a counting unit and need not be an isolated particle.
Covalent bond
A link between atoms with shared electrons. The single, double and triple line labels describe the number of shared pairs in the electron dot model.
Ionic solid
A solid held together by electrical attractions in an extended array of ions. Use the MgS example to check how a change in the electron count gives each ion its charge.
Diatomic
In the C–Se model this course term describes the complete unit. Count the labeled atoms in the model and check separately whether they come from the same element.
