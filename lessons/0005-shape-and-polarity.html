Combine bond effects

Use a bond’s electron pull and a molecule’s supplied shape as two separate clues.

Start with one bond and the scale used to describe it. Use the main exit check to see how that reasoning differs from a claim about the whole molecule. An optional activity lets you explore how the effects combine. Open the glossary or use the quick reference.

First: how uneven is one bond?

Electronegativity describes an atom’s pull on shared electrons. Compare two values using the absolute difference: larger minus smaller, or zero when the values are equal. The values are unitless. A greater difference usually means more uneven sharing. Equal values give zero, so this simple comparison has no stronger-pulling end. When the pulls differ, the stronger-pulling end has a partial negative charge, written δ−; the other end is δ+. “Partial” means less than a whole ion charge.

For invented values 2.9 and 2.1, the difference is 0.8. Different courses use different cutoffs for naming regions on a scale. Real bonding changes gradually across those cutoffs. In your own work, take both values from the same supplied scale and apply the course’s own key.

Check the bond and the whole molecule

A bond line represents a shared pair. The difference in electron pull describes how unevenly the electrons are shared. To describe a whole molecule, also look at how the bond effects point in space. Equal effects pointing in opposite directions balance each other, so there can be uneven sharing in a bond even when the modeled effects balance overall.

Main exit check

A second line is then drawn between the same atoms to show another shared pair, with the ratings held fixed for this exercise. What changes in the drawing? What happens to the difference?

Optional extension · combine arrows

Start with the directions

To reason about a whole molecule, consider both the local electron-pull effects and the three-dimensional arrangement of atoms. A name for one local effect is not enough to classify the whole particle. First obtain the shape from a supplied three-dimensional model or an appropriate shape method. One such method is VSEPR, a model in which electron groups around an atom spread apart. Here the angles are supplied. A flat Lewis drawing records connections and electron pairs. Ask for shape evidence before treating its angles as molecular geometry.

A vector is an arrow with a size (its magnitude) and a direction. For an introductory arrow model, draw each bond’s polarity arrow toward its more electron-attracting end. Combine the arrows in the supplied geometry. Equal arrows in opposite directions cancel; arrows at an angle may leave a net (combined) effect. Unequal opposite arrows do not fully cancel.

These arrows are a qualitative model of charge distribution, not moving electrons, bond order, or measured charge separation in an actual molecule.

Predict → bend the model → explain

Two equal outward arrows start in opposite directions. Predict what happens to their combined effect when the supplied angle shrinks to 90°. Only the angle changes; both arrow lengths stay fixed.

Compare reasoning after an attempt

Yes. The two horizontal contributions cancel, leaving one unit upward. One unit downward returns to the start. Equal contributions must oppose in direction as well as match in size.

Compare the construction after attempting it

The first and third arrows cancel horizontally. The end of the three-arrow path is one unit above its start. Add one unit down to close the path. A closed path has no start-to-finish separation, so its combined arrow is zero.

Identify the original start and the final tip after all three supplied arrows.

Hint 2: Recall

A closed head-to-tail path ends where it started, so its combined arrow has zero length.

Hint 3: Choose a strategy

Draw all three supplied arrows head to tail. Then sketch a closing arrow from their final tip back to the original start; determine its direction and length.

Extension exit · predict the direction

Two model arrows point right and one points left. All three have the same length. Describe the combined arrow without calculating angles. What would change if the leftward arrow were twice as long?

Compare after making an attempt

With equal lengths, one rightward arrow balances the leftward one. The result is one arrow length to the right. If the leftward arrow doubles, it balances both rightward arrows and the combined effect is zero. If you counted arrows without checking their lengths, draw the three arrows head to tail and compare the start and finish.

Glossary: tools for thinking

Absolute difference / ≤ / ≥
The distance between values, including zero for equal values. ≤ includes values less than or equal to its boundary; ≥ includes greater values and the boundary.
Electronegativity / Δ
Electronegativity describes attraction for shared electrons. Δ means difference; here use larger minus smaller on the same unitless scale.
δ / partial
The Greek letter δ indicates a partial charge in this context: a fraction of a whole unit charge.
Geometry
The arrangement of parts in space, including angles and directions.
Vector / magnitude / net
A vector has size and direction. Magnitude means its size. Net is the combined result.
VSEPR
Valence-shell electron-pair repulsion: a model using electron groups to help predict arrangement in space.
