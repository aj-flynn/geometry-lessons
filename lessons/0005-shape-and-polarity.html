Combine bond effects

Use a bond’s electron pull and a molecule’s supplied shape as two separate clues.

Learn one method at a time. Stop after a check if you need a break; return to your own work after the exit explanation. Open the glossary or use the quick reference.

First: how uneven is one bond?

Electronegativity describes an atom’s pull on shared electrons. Compare two values using the absolute difference: larger minus smaller, or zero when the values are equal. The values are unitless. A greater difference usually means more uneven sharing. Equal values give zero, so this simple comparison has no stronger-pulling end. When the pulls differ, the stronger-pulling end has a partial negative charge, written δ−; the other end is δ+. “Partial” means less than a whole ion charge.

For invented values 2.9 and 2.1, the difference is 0.8. Numerical cutoffs on introductory charts are approximate classroom conventions, not sharp physical boundaries. Boundaries and labels vary by course; consult the supplied chart and make the classification independently. Use the table and convention your teacher supplies. Real bonding lies on a continuum, so a difference alone is not a complete explanation.

Then: do the bond effects cancel?

To reason about a whole molecule, consider both the local electron-pull effects and the three-dimensional arrangement of atoms. A name for one local effect is not enough to classify the whole particle. First obtain the shape from a supplied three-dimensional model or an appropriate shape method. One such method is VSEPR (electron groups around an atom spread apart). To use it, count regions around the atom: each bonded neighbor is one region even if several pairs are shared, and each lone pair is another region. Predict the regions’ arrangement first, then describe the atoms’ positions. This lesson explores supplied angles; it does not derive the shape of an unknown molecule. A Lewis structure helps identify those groups, but its flat arrangement is not itself proof of shape.

A vector is an arrow with a size (its magnitude) and a direction. For an introductory arrow model, draw each bond’s polarity arrow toward its more electron-attracting end. Combine the arrows in the supplied geometry. Equal arrows in opposite directions cancel; arrows at an angle may leave a net (combined) effect. Unequal opposite arrows do not fully cancel.

These arrows are a qualitative model of charge distribution, not moving electrons, bond order, or measured charge separation in an actual molecule.

Exit check: explain your evidence

Two tasks arrive together: one gives a pair of electronegativity values and a classification key; the other gives three arrows arranged in space. Which method belongs to each task? What additional evidence would be needed if the second task instead supplied only a flat electron drawing?

Check your method after making an attempt

Use the absolute difference and supplied key for the first task. Combine all arrows for the second. Request reliable geometry and evidence about the size and direction of the relevant charge effects if only a flat drawing is available. A flat electron-accounting drawing does not establish the three-dimensional arrangement. Combine the effects only after those facts are available.

If this is difficult, return to the model, make one change, and describe what stays the same. Then explain the checking method without looking.

Glossary: tools for thinking

Absolute difference / ≤ / ≥
The distance between values, including zero for equal values. ≤ includes values less than or equal to its boundary; ≥ includes greater values and the boundary.
Electronegativity / Δ
Electronegativity describes attraction for shared electrons. Δ means difference; here use larger minus smaller on the same unitless scale.
δ / partial
The Greek letter δ indicates a partial charge in this context: a fraction of a whole unit charge.
Geometry
The arrangement of parts in space, including angles and directions.
Vector / magnitude / net
A vector has size and direction. Magnitude means its size. Net is the combined result.
VSEPR
Valence-shell electron-pair repulsion: a model using electron groups to help predict arrangement in space.
