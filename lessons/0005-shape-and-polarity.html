Combine bond effects

Use a bond’s electron pull and a molecule’s supplied shape as two separate clues.

Start with one bond and the scale used to describe it. Use the main exit check to see how that reasoning differs from a claim about the whole molecule. An optional activity lets you explore how the effects combine. Open the glossary or use the quick reference.

First: how uneven is one bond?

Electronegativity describes an atom’s pull on shared electrons. Find the absolute difference by subtracting the smaller value from the larger one. Equal values give zero. The symbol ΔEN stands for this difference. The values are unitless. A greater difference usually means more uneven sharing. When the pulls differ, label the stronger-pulling end δ− for partial negative and the weaker-pulling end δ+ for partial positive. “Partial” means a fraction of a full unit of charge.

For invented values 2.9 and 2.1, the difference is 0.8. Different courses use different cutoffs for naming regions on a scale. Real bonding changes gradually across those cutoffs. In your own work, take both values from the same supplied scale and apply the course’s own key.

Check the bond and the whole molecule

A bond line represents a shared pair. The difference in electron pull describes how unevenly the electrons are shared. To describe a whole molecule, use its geometry, the arrangement of its atoms in space, to see how the bond effects point. Equal effects pointing in opposite directions balance each other, so there can be uneven sharing in a bond even when the modeled effects balance overall.

Main exit check

One bond. In a training diagram, the left end is rated 3.3 and the right end is rated 2.6. Use the display key above to choose a fill. Draw the dipole arrow with its crossed tail and label δ+ and δ−. A second line is then drawn between the same atoms to show another shared pair, with the ratings held fixed for this exercise. What changes in the drawing? What happens to the difference?

A whole molecule. A separate shape model shows two opposing bond effects. One is stronger. Would the two effects balance completely? What information would you ask for if you had only a flat drawing of the connections?

Hint · match the evidence to the question

For one bond, use the ratings for the difference and put the tip toward the higher rating. Count bond lines for shared pairs. For the whole molecule, compare both the directions and the strengths of the effects.

Compare after explaining both cases

ΔEN = 3.3 − 2.6 = 0.7, in the solid row. The tip points left toward 3.3 (δ−). Draw the crossed tail on the right at 2.6 (δ+). The extra line records an extra pair, and the fixed ratings still give 0.7. If you changed the difference when the line was added, recalculate using only the ratings.

The opposing effects partly balance. The stronger one leaves a combined effect in its direction. If you had only a connection drawing, ask for the molecule’s shape in space and the relative strengths and directions of the bond effects. If you assumed that opposite directions always balance, sketch two opposing crossed-tail bond arrows of unequal length and explain which direction remains.

Optional extension · combine arrows

Start with the directions

To reason about a whole molecule, consider both the local electron-pull effects and the three-dimensional arrangement of atoms. A name for one local effect is not enough to classify the whole particle. First obtain the shape from a supplied three-dimensional model or an appropriate shape method. One such method is VSEPR, a model in which electron groups around an atom spread apart. Here the angles are supplied. A flat Lewis drawing records connections and electron pairs. Ask for shape evidence before treating its angles as molecular geometry.

A vector has size and direction. To model how bond effects add, first draw each bond dipole with the chemical notation from above. Then copy its direction and relative length as a plain math arrow. Use the plain arrows to find the combined effect, or resultant. Equal arrows in opposite directions cancel. Unequal opposite arrows leave a resultant toward the longer arrow.

The plain arrows keep the directions and relative strengths of the bond effects. The dashed resultant represents their sum in the model.

Predict, change the angle, explain

Two equal vectors start in opposite directions. Predict what happens to their resultant when the supplied angle shrinks to 90°. Both vector lengths stay fixed. Yes. The two horizontal contributions cancel, leaving one unit upward. One unit downward returns to the start. Equal contributions must oppose in direction as well as match in size.

The first and third arrows cancel horizontally. The end of the three-arrow path is one unit above its start. Add one unit down to close the path. A closed path has no start-to-finish separation, so its combined arrow is zero.

Extension exit · predict the direction

Two model arrows point right and one points left. All three have the same length. Describe the combined arrow without calculating angles. What would change if the leftward arrow were twice as long?

Compare after making an attempt

With equal lengths, one rightward arrow balances the leftward one. The result is one arrow length to the right. If the leftward arrow doubles, it balances both rightward arrows and the combined effect is zero. If you counted arrows without checking their lengths, draw the three arrows head to tail and compare the start and finish.

Glossary: tools for thinking

Absolute difference / ≤ / ≥
The distance between values, including zero for equal values. ≤ includes values less than or equal to its boundary; ≥ includes greater values and the boundary.
Electronegativity / ΔEN
Electronegativity describes attraction for shared electrons. ΔEN is the difference between two electronegativity values. Subtract the smaller value from the larger one on the same unitless scale.
δ / partial
The Greek letter δ marks a partial charge, a fraction of a whole unit of charge.
Bond dipole arrow
The crossed tail marks the δ+ end of a bond. The tip points to the δ− end.
Geometry
The arrangement of parts in space, including angles and directions.
Vector / magnitude / net / resultant
A vector has size and direction. Magnitude means its size. Net means overall or combined. A resultant is the vector you get by adding vectors.
VSEPR
Valence-shell electron-pair repulsion is a model that uses electron groups to help predict arrangement in space.
